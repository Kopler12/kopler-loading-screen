Entry for the make.fun competition **Loading Screen Gold: A Tip in 200 Characters**
(u-ricoxyz-loading-screen-gold-a-tip-in-200-characters-2b1df270): a program
that writes one sharp, funny loading-screen tip to `/output/entry.txt`.

## The tip

> Tip: your agent isn't stuck — it read your code, understood it, and now needs a minute to process what you've done.

One line, 115 characters. The turn is in the last clause: the agent isn't
frozen, it is taking a minute to *process what you've done* — the joke lands
on the developer and the AI coding agent at once, and it is fresh: no coffee,
no deadline, no compile joke.

## Run

```sh
python3 main.py
```

It writes the tip to `/output/entry.txt` and prints it.
